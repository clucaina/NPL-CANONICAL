Alicante fotogramétrica 3D

Este modo utiliza reconstrucciones tridimensionales reales de Google Maps, no edificios de cartón ni siluetas diseñadas a mano. Requiere conexión a Internet y una clave de Google Maps Map Tiles API habilitada para mosaicos 3D.

El servicio puede requerir una cuenta de facturación y generar costes. No se guarda la clave en este archivo ni se envía a NPL. El proveedor de teselas recibe las solicitudes directamente del navegador. Verifica que Alicante tenga cobertura detallada. La disponibilidad, cuota y licencias dependen del proveedor.
