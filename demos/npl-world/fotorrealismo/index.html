NPL WORLD / ALICANTE · PRIORIDAD VISUAL

Alicante real, no edificios inventados

Este visor utiliza mallas fotogramétricas 3D con textura real, no cubos, fachadas aleatorias ni una fotografía pegada sobre un plano. La cámara comienza en la Explanada.

La clave es necesaria para descargar la geometría. Debes activar Map Tiles API y facturación en Google Cloud. No se guarda en el navegador ni se añade al repositorio. El proveedor puede cobrar según uso; configura cuotas y restricciones de seguridad. Las licencias de Google exigen mostrar atribuciones. No hay modo low-poly que oculte fallos de carga.

La precisión visual dependerá de la cobertura de Google en estas coordenadas. El modelo humano predeterminado es genérico y no representa el rostro de Lucía; para reproducirlo necesitamos un GLB personalizado.
